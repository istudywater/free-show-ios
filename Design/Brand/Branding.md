# FreeShow Controller

Created using the built-in image generation tool, with the user's Smixx artwork as visual references. The presentation-screen symbol distinguishes this app while retaining orange, near-white, charcoal, and a restrained cyan accent. The startup screen follows Smixx's dimensional geometric panel composition.

- `freeshow-controller-logo-v1.png`: original generated square symbol; the app icon is proportionally resized to 1024 × 1024, opaque RGB, with square corners for system masking.
- `freeshow-controller-start-v1.png`: original landscape startup artwork, retained for reference.
- `freeshow-controller-start-v2.png`: active startup artwork; the logo and wordmark are centered within the charcoal panel.

Both assets are copied into the application asset catalog. LaunchScreen.storyboard displays the startup art with aspect-fit constraints so the wordmark remains visible in portrait and landscape. The system controls launch-screen duration; there is no artificial startup delay.

The Xcode project, app target, shared scheme, app source folder, executable, visible app labels, and documentation use FreeShow Controller. The original bundle identifier, Keychain service, and preferences key are intentionally retained to update the installed app and preserve saved settings. RemoteShow remains the desktop protocol's name; upstream FreeShow Remote references retain their official names.
